# Operatto 🍽️

### Gestão inteligente para restaurantes.

O Operatto é um sistema desenvolvido para facilitar a gestão operacional de restaurantes.

## Funcionalidades

- Controle de estoque
- Registro de entradas e saídas
- Controle de perdas
- Inventário e contagem física
- Gestão de funcionários
- Checklists operacionais
- Histórico de movimentações
- Painel exclusivo para gerentes

## Objetivo

Organizar a operação do restaurante, reduzir desperdícios e melhorar o controle da equipe.
